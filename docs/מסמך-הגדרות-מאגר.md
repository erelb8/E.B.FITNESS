## 6. אבטחת המידע

**בקרת גישה**
- המאמן נכנס בדוא״ל וסיסמה מול Supabase Auth
- כל טבלה מוגנת ב־Row Level Security; מאמן רואה אך ורק את המתאמנים שלו
- המתאמן ניגש דרך קישור אישי ייחודי או שם משתמש וסיסמה
- סיסמאות מתאמנים מגובבות (bcrypt) ואינן ניתנות לשחזור
- חמישה כישלונות התחברות נועלים את החשבון לחמש עשרה דקות

**הצפנה**
- תעבורה: HTTPS/TLS בלבד
- מנוחה: הצפנת דיסק בצד Supabase

**עקרונות**
- הגישה למידע רפואי מוגבלת לפונקציות שרת ייעודיות, ולא לטבלה ישירות
- מפתח ה־API הפומבי בלבד נמצא בקוד; מפתח `service_role` אינו בשימוש
  ואינו מופיע בשום מקום בקוד
- קבצי לקוחות אינם נשמרים במאגר הקוד הפומבי
