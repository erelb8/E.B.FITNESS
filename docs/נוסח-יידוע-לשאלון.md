# נוסח יידוע לשאלון הקליטה

שאלון הקליטה נמצא **מחוץ לאפליקציה** — טופס גוגל, מסמך, או נייר.
באפליקציה עצמה היידוע כבר מוטמע אוטומטית מעל הצהרת הבריאות.
כאן צריך להוסיף אותו ידנית, פעם אחת, לשאלון שלך.

**איפה לשים:** בראש השאלון, **לפני השאלות הרפואיות** — לא בסוף
ולא כקישור. רשות הגנת הפרטיות קבעה שקישור למדיניות אינו תחליף
להצגה במקום שבו האדם ממלא את הפרטים.

## שלושה כללים שלא לשבור

**התיבה אינה מסומנת מראש.** סימון מראש אינו הסכמה, והוא מבטל את
תוקפה. חובה שהמתאמן יסמן בעצמו.

**בלי סימון — אין למלא.** אם זה טופס גוגל, הגדר את השאלה כ**חובה**.

**כשמשנים את הנוסח — משנים את התאריך.** באפליקציה גרסת הנוסח נשמרת
אוטומטית עם כל הסכמה. כאן צריך לרשום ידנית מתי כל מתאמן הסכים
ולאיזה נוסח, אחרת אי אפשר להוכיח על מה בדיוק הוא הסכים.
