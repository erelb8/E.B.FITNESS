# E.B FIT — ניהול מתאמנים

אפליקציית PWA לניהול מתאמנים: תיקי מתאמנים, תוכניות אימון, יומן, מדידות והתקדמות, ותשלומים.
כל הנתונים נשמרים מקומית במכשיר (localStorage) — אין שרת ואין חשבון.

## התקנה באייפון
1. לפתוח את כתובת האתר ב-**Safari** (חייב Safari, לא Chrome).
2. ללחוץ על כפתור **שיתוף** (הריבוע עם החץ למעלה).
3. לבחור **הוספה למסך הבית**.

מאותו רגע האפליקציה נפתחת במסך מלא עם אייקון משלה, ועובדת גם בלי אינטרנט.

## פיתוח מקומי
```
python -m http.server 8080
```
ואז לפתוח http://localhost:8080

> Service Worker רץ רק ב-https או ב-localhost. פתיחה ישירה של הקובץ (file://) לא תשמור נתונים.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — HTML, CSS ו-JS בקובץ אחד |
| `manifest.json` | הגדרות ההתקנה: שם, אייקונים, מסך מלא |
| `sw.js` | Service Worker — שמירה במכשיר לעבודה אופליין |
| `icons/` | אייקונים לכל הגדלים |

## עדכון גרסה
אחרי שינוי ב-`index.html`, להעלות את `VERSION` בראש `sw.js` כדי שהמכשירים ימשכו את הגרסה החדשה.
